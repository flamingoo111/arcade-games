# Квадратикус: Фабрика Путей

Лёгкая 2D веб-игра в стиле idle-tycoon с профориентационным уклоном.

## Установка и запуск

```bash
pip install flask
python app.py
```

Откройте браузер на `http://localhost:5000`

## Структура проекта

```
/app
  /static
    /css
      style.css
    /js
      game.js
      config.js
      utils.js
  /templates
    index.html
app.py
```

## Технический стек

- **Backend:** Flask
- **Frontend:** HTML5 + CSS3 + Vanilla JavaScript
- **Graphics:** Canvas 2D
- **Никаких зависимостей:** чистый код
